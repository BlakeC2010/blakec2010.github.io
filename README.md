# Blake's portfolio

A straightforward personal site made with HTML, CSS, and a little JavaScript.

## Editing

- To change **words**, open `website-content.md`. Edit text under the `###` labels.
- To change **colors, spacing or layout**, edit `styles.css`.
- To rebuild the page after editing words, run: `python build_site.py`.
- Open `index.html` to preview it locally.
- Commit the changed files to the `main` branch of `BlakeC2010/blakec2010.github.io` to update GitHub Pages.

The page deliberately uses simple sections, a small set of colors, and no visual libraries or trackers. It is usable without JavaScript.

## Resume

The link points to `assets/resume.pdf`. To update it, replace that file with your latest PDF.

**Privacy:** The public resume contains a phone number. Consider replacing it with a version that uses only your email before sharing the site broadly.
