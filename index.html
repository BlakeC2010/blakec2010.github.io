Featured Project

Context Titles

Context Titles is an Obsidian community plugin that makes duplicate note names easier to understand in Graph View by adding folder context to repeated labels.

Finished and published

What it is

Context Titles adds folder context to repeated note labels in Graph View and Local Graph so duplicate files are easier to understand at a glance.

Why it matters

In Obsidian, repeated notes like Overview.md, Tasks.md, and Research.md can be confusing in Graph View because they all look the same. Context Titles helps by showing labels like Hardware Notes - Research or Portfolio Website - Overview.

The real files are not renamed, and the plugin does not edit note contents. It only changes how duplicate note names appear in graph labels.
