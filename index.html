01 / Where it started

Curiosity turned into a habit.

01.

“I want to build something that matters beyond my own computer.”

— Blake

When I was eight or nine, I watched YouTubers build games and wanted to know how they did it. That led me to programming, then AI, then the idea of building applications and tools of my own. My interests kept changing, but the part I liked stayed the same: taking something I didn't understand and working on it until I did.

I'm especially comfortable troubleshooting computers and working through software problems. I like projects that let me combine both sides of technology. I've learned that getting something running is one challenge; making it reliable enough to use regularly is another.

An Obsidian community plugin

Context Titles

I built Context Titles to solve a small but frustrating problem: when multiple notes have the same name, Obsidian's Graph View can make them hard to tell apart. The plugin adds just enough folder context to distinguish them without renaming the actual files.

It supports Graph View and Local Graph, configurable label depth, folder rules, and live settings previews.

  • TypeScript
  • Obsidian
  • GitHub Actions

A Chrome browser extension

AI Chat Notifications

I wanted to know when an AI chat finished answering without having to watch the tab. This extension notifies me when a supported chat finishes while it's hidden, then takes me back to the right conversation when I click.

It supports ChatGPT, Claude, and Gemini, with local notification settings and no external analytics.

Listen→Understand→Act

My long-running AI assistant project

Zoro

Zoro started as a simple voice-command experiment and has turned into a Windows-first assistant that connects speech, local AI models, and desktop actions. It's the project that has taught me the most about integrating systems and dealing with things that break.

I've worked on wake-word detection, speech recognition, Ollama model routing, desktop commands, voice responses, and the constant debugging needed to make those parts work together. It's still a work in progress.

  • Python
  • Ollama
  • Speech recognition
  • Windows automation

A Windows repository-sync tool

GitHub Sync

This is an ongoing Windows app project for keeping local GitHub repositories in sync while protecting unfinished local work. The main challenge is deciding when it's safe to update files — and when the app should stop and ask for attention.

The project explores a system-tray interface, Git-aware checks, and a safer approach to automatic updates. It isn't publicly released yet.

  • Tauri
  • Rust
  • React
  • Git
