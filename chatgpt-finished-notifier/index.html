Built to stay out of your way

Notifications that adapt to how you work.

Choose one mode and the extension handles the rest.

01

Auto

Uses the custom browser toast while Chrome is active, then falls back to a system notification when you are outside Chrome.

Recommended
02

Browser Toast

A clean extension-owned notification inside Chrome, with a direct Open chat action and automatic dismissal.

03

System

Uses Chrome's native notification API so Windows or macOS can show the alert through the operating system.

Multi-monitor aware

If the ChatGPT tab is still visible, it stays quiet.

The extension checks whether the ChatGPT page is actually hidden. Keeping the chat visible on another monitor will not trigger a notification just because you clicked somewhere else.

Privacy by design

Your conversations are not collected.

The extension watches ChatGPT interface state so it can tell when a response begins and ends. It does not store or transmit your prompts or responses, and it does not use analytics or an external server.
