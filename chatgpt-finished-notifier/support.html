Support

Help when something doesn't behave.

ChatGPT Finished Notifier · v1.2.0

No notification appears

First check whether the ChatGPT tab was actually hidden when the response finished. The extension intentionally stays quiet while the ChatGPT tab is still visible, including when it remains visible on another monitor.

If you use System mode, make sure Chrome notifications are enabled in your operating system. On Windows 11, also check Settings → System → Notifications → Do not disturb. Windows can automatically enable Do Not Disturb during full-screen apps, gaming, display duplication, Focus sessions, or configured quiet hours.

The custom browser toast does not appear

Open the extension's options page and confirm that the notification mode is set to Auto or Browser Toast. Auto uses the custom toast while Chrome is the active application and falls back to a system notification when needed.

I want to change notification mode

Open Chrome's Extensions page, select ChatGPT Finished Notifier, then open the extension options. Choose Auto, Browser Toast, or System. Your preference is remembered by Chrome extension storage.

The extension stopped detecting responses

Refresh the ChatGPT tab after updating or reinstalling the extension. Chrome content scripts that were loaded before an extension update may continue using the older version until the page is refreshed.

Service worker says “Inactive”

That is normal for Manifest V3 Chrome extensions. Chrome suspends extension service workers while they are idle and wakes them again when an event needs to be handled. “Inactive” by itself does not mean the extension is broken.

Report a bug

If the steps above do not solve the problem, open an issue on GitHub. Include what notification mode you were using, your operating system, what you expected to happen, and what actually happened. Do not include private ChatGPT conversation content.
